# Teste com usuários reais

Roteiro curto (30 a 40 minutos por pessoa) para descobrir onde membros da
igreja **travam** no ChurchApp. O objetivo não é avaliar a pessoa, e sim o app:
se alguém não consegue fazer uma tarefa, o problema é da tela.

Com 3 pessoas já aparecem os problemas mais graves; com 5 aparecem quase
todos. Repita depois de cada rodada de correções.

## Quem convidar

Escolha perfis diferentes, de preferência gente que **ainda não usou** o app:

| # | Perfil | Por quê |
| --- | --- | --- |
| 1 | Membro com pouca familiaridade com celular (ex.: 60+ anos) | Mostra tudo que depende de "saber usar app" |
| 2 | Voluntário de ministério (louvor, recepção, mídia) | É quem mais usa escalas no dia a dia |
| 3 | Líder de ministério | Confere se montar escala é claro para quem organiza |

Evite quem ajudou a construir o app, o pastor que já conhece tudo e pessoas
da área de tecnologia (elas "dão um jeito" e escondem os problemas).

## Preparação (no dia anterior)

- [ ] Criar uma **igreja de teste** (não use a igreja real: as ações enviam
      notificações e mensagens).
- [ ] Criar um ministério "Louvor" com 2 ou 3 voluntários de exemplo.
- [ ] Criar uma **escala para o próximo domingo** com o participante escalado
      como "Vocal".
- [ ] Criar uma conta para cada participante, já vinculada à igreja de teste
      (Admin › Pessoas › Adicionar). Anote e-mail e senha temporária.
- [ ] Testar o roteiro inteiro uma vez você mesmo, no celular.
- [ ] Ter à mão: este roteiro impresso, papel para anotar e, se a pessoa
      aceitar, o celular gravando a tela.

O teste deve ser feito **no celular da própria pessoa**, que é como ela vai
usar no dia a dia.

## Como conduzir

Uma pessoa conduz e anota. Fale pouco e **não ajude**. Quando a pessoa
perguntar "e agora?", devolva: *"O que você faria se eu não estivesse aqui?"*.
Só ajude se ela travar por mais de 2 minutos; anote que precisou de ajuda.

Peça para ela **pensar em voz alta**: falar o que está procurando, o que
espera que aconteça e o que a deixou em dúvida.

### Texto de abertura (leia para a pessoa)

> Obrigado por ajudar! Vamos testar um aplicativo da igreja, não você. Não
> existe resposta errada: se algo for difícil, é o aplicativo que precisa
> melhorar, e é exatamente isso que queremos descobrir. Vou pedir algumas
> tarefas e ficar só observando. Tente falar em voz alta o que está pensando
> enquanto usa. Posso anotar e gravar a tela? Nada sai daqui.

## As tarefas

Leia **uma de cada vez**, exatamente como está escrito. Não diga o nome dos
botões nem onde ficam.

### Tarefa 0: Entrar no app

> "Você recebeu este e-mail e esta senha da igreja. Entre no aplicativo."

- **Sucesso:** chega à tela inicial (inclusive trocando a senha temporária,
  se o app pedir).
- **Observe:** encontra onde digitar? Entende o pedido de trocar a senha?
  Aparece o convite para instalar o app? A pessoa entende o que é?

### Tarefa 1: Confirmar uma escala

> "O líder do louvor te colocou para cantar no próximo domingo. Avise que você
> vai."

- **Sucesso:** a escala do domingo fica como **confirmada**.
- **Observe:** vai pelo Início, pela aba Escalas ou pelo sino? Reconhece que
  está escalado e em qual função? Entende a diferença entre "Confirmar" e
  "Não posso"? Percebe que deu certo (mensagem, cor, ícone)?
- **Variação (opcional):** "Agora imagine que surgiu um compromisso. Avise que
  não vai poder ir e explique o motivo."

### Tarefa 2: Pedir oração

> "Sua mãe vai fazer uma cirurgia na quinta. Peça oração para a igreja, mas sem
> que apareça o seu nome."

- **Sucesso:** o pedido é enviado **como anônimo**.
- **Observe:** encontra "Oração" (fica no menu "Mais" no celular)? Entende a
  opção "Publicar como anônimo"? Entende que o pedido passa pela revisão do
  pastor antes de aparecer? Fica ansiosa por não ver o pedido na lista logo
  depois de enviar?

### Tarefa 3: Marcar indisponibilidade

> "Você vai viajar no dia 20 do mês que vem. Avise o app que nesse dia você não
> pode servir."

- **Sucesso:** a data aparece na lista de indisponibilidades.
- **Observe:** encontra o lugar (fica no Perfil)? Consegue usar o seletor de
  data? Percebe que precisa tocar no "+" para adicionar? Percebe que precisa
  tocar em "Salvar Perfil" depois? (Hoje a data **não é salva** só com o "+":
  se a pessoa sair da tela sem salvar, a indisponibilidade se perde. Anote
  quantas pessoas caem nisso.)

### Tarefa extra para o líder (perfil 3)

> "Monte a escala do louvor do outro domingo com duas pessoas: uma no violão e
> outra no vocal."

- **Sucesso:** a escala é criada com as duas pessoas e funções.
- **Observe:** acha onde criar? Entende os campos? Sabe se as pessoas foram
  avisadas?

## Perguntas finais (5 minutos)

1. De 1 a 5, quão fácil foi usar o app? Por quê?
2. O que foi mais confuso?
3. Teve alguma palavra que você não entendeu?
4. Você usaria isso no lugar do grupo de WhatsApp? O que faltaria?
5. Tem algo que você esperava encontrar e não achou?

## Ficha de anotação (uma por pessoa)

| Tarefa | Conseguiu? (sim / com ajuda / não) | Tempo | Onde travou | O que disse |
| --- | --- | --- | --- | --- |
| 0. Entrar | | | | |
| 1. Confirmar escala | | | | |
| 2. Pedir oração anônima | | | | |
| 3. Indisponibilidade | | | | |
| Extra (líder) | | | | |

Anote as **frases exatas** da pessoa ("cadê o botão de…", "isso aqui é o
quê?"): elas mostram o problema melhor que qualquer resumo.

## Depois do teste

1. Junte as fichas e liste cada problema **uma vez**, com quantas pessoas
   passaram por ele.
2. Classifique:
   - **Grave:** a pessoa não conseguiu terminar a tarefa sozinha.
   - **Médio:** conseguiu, mas travou, errou o caminho ou ficou insegura.
   - **Leve:** comentou, estranhou, mas seguiu sem dificuldade.
3. Corrija primeiro os graves que apareceram em mais de uma pessoa.
4. Repita o teste com **pessoas novas** depois das correções: quem já fez o
   teste aprendeu o caminho e não serve mais para medir.
